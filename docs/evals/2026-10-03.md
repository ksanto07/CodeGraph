## Native agent

Three fixture questions use the real Managed Deep Agents HTTP runtime and
`gpt-5.6-sol` through the application's wrapped client. Eight model rounds
perform twelve successful graph lookups. Each answer has current-turn lookup
evidence, and all three exact-path scores are 1. The change-impact question
uses the existing incoming graph walk. The quality question declines grading.

An initial answer guesses middleware behavior from import edges. A narrow
instruction change removes that guess in the subsequent three-question check.
Remaining heuristic plumbing flags match the word runtime in statements about
what the graph cannot establish. They are inspection aids, not verified
claims that the agent discusses its internal transport.

Synthetic native checks cover unauthorized registration, foreign threads,
stolen and revoked handles, streamed lookup events and credential redaction.
The local launcher starts seven native processes and leaves zero orphans after
shutdown. This fixture does not prove the full Clerk-to-browser journey;
manual acceptance remains the user's check under AGENTS.md.
